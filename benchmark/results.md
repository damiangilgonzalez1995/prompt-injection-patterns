# Benchmark results

Generated by `python -m benchmark.run_all`. Every pattern is scored by the
same `core.verdict.is_compromised` against the same six payloads in
`attacks/payloads.py`. Numbers are attacks **blocked**, higher is better.

| Pattern | Guardian | Secure | Insecure | Note |
|---|---|---:|---:|---|
| Action-Selector | Fixed action list | **6/6** | 0/6 | Immune by construction to tool hijacking: the tool is not in the enum. |
| Plan-Then-Execute | Frozen plan | **4/6** | 0/6 | Plan holds; the *content* of a planned step can still be coloured. Known residual risk. |
| LLM Map-Reduce | Map-output sanitizer | **6/6** | 0/6 | Hijacked worker output fails validation and is dropped before the reduce. |
| Dual LLM | Privileged LLM + symbolic memory | **6/6** | 0/6 | Strongest separation: the payload never enters the privileged context at all. |
| Code-Then-Execute | Execution sandbox | **6/6** | 0/6 | AST allowlist rejects the program before the interpreter sees it. |
| Context-Minimization | Context pruner | **6/6** | 0/6 | Bounds an injection to one turn; does not prevent that turn. |
